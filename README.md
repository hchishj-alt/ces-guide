# CES 가이드

CES에 처음 가는 연수생을 위한 웹앱이에요. 설치 없이 폰 브라우저로 열고, 홈 화면에 추가하면 앱처럼 써요.

- **오늘**: 그날 둘러볼 구역, 정해진 시간(남은 시간), "뭐 볼까?" 추천(위시 1 · 관심 분야 1 · 의외의 것 1)
- **지도**: 홀별 3D/위에서 보기, 내 위치와 바라보는 방향, 길안내, 물·화장실·음식·충전·출구 바로가기, 주머니 모드
- **위시**: 가고 싶은 부스 모으기, 근처(60m)에 오면 알림, 누르면 지도에서 3D로 미리 보기
- **기록**: 부스마다 사진·음성(받아 적기)·글·별점·대화, 날짜·홀·종류별 모아보기와 검색, 파일로 내보내기
- **번역**: 상대 영어 → 한국어 자막, 내 한국어 → 큰 영어 화면 + 읽어 주기, 부스 분야별 질문 추천(질문은 인터넷 없이도 됨)

## 내 위치를 잡는 방법
체크인 버튼은 없어요. 부스를 눌러 기록하면 그 부스 앞으로 위치가 맞춰지고, 그 사이는 걸음 수와 나침반으로 점을 옮겨요.
지도를 꾹 누르면 "나 여기"로 바로 옮길 수 있어요. GPS는 어느 건물인지만 봐요(실내에서는 부스를 구분할 만큼 정확하지 않아서).

## 데이터 구조 (나중에 다른 연수생이 쓰기 쉽게)
| 층 | 파일 | 내용 |
|---|---|---|
| 전시장 | `data.js` `HALLS` | 홀 크기, 부스(번호·이름·분야), 편의시설. **지금 배치는 예시**예요. 12월에 CES 공식 전개도가 나오면 `named`에 실제 x·y·w·h를 넣고 `SAMPLE=false` |
| 연수 묶음 | `data.js` `TRIPS` | 날짜별 구역, 정해진 시간, 처음 위시 후보. 호텔·항공·연락처는 넣지 않아요 |
| 내 것 | 폰 안 IndexedDB(`store.js`) | 관심 분야, 위시, 본 곳, 별점, 사진·음성·메모. 서버로 보내지 않아요 |

## 보안
- 개인 기록은 폰 브라우저 안에만 저장. 번역할 때만 그 문장이 Google Gemini로 가요.
- 번역 키는 각자 폰에서 넣고 그 폰에만 저장(저장소·코드에 없음). 화면에 넣는 글은 전부 이스케이프.
- 페이지에 CSP를 걸어 스크립트는 이 사이트 것만, 연결은 Gemini 주소만 허용.
- 외부 리소스: Pretendard 글꼴 v1.3.9(jsDelivr, SIL OFL 1.1) 하나뿐. 빌드 도구·npm 의존성 없음.

## 고칠 때
- `app.js`의 `VERSION`과 `sw.js`의 `VERSION`을 같이 올려야 폰이 새 코드를 받아요.
- 로컬 확인: `python3 -m http.server 8790` 후 `http://localhost:8790/`
